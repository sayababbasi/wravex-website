# Project Requirements

## 1. Project Overview
Wravex Innovation is a software development company providing technology solutions. The website must establish Wravex as a professional, modern, and trustworthy technology company.

## 2. Primary Goals
- Establish credibility
- Explain services
- Generate leads
- Showcase technical capability
- Build a scalable company identity

## 3. Target Audience
- Business Owners (Custom software)
- Startups (MVP, SaaS, AI integration)
- Established Businesses (Automation, ERP/CRM)

## 4. Brand Personality
Innovative, Professional, Intelligent, Reliable, Fast, Business-focused, Modern, Confident.
Avoid looking cheap, generic, overly flashy, cyberpunk, or gaming-oriented.
