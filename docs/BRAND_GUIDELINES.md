# Brand Guidelines

## Visual Identity
- **Primary Navy**: #0B2A5B
- **Deep Navy**: #071A3A
- **Royal Blue**: #1261C9
- **Cyan**: #20B8E8
- **White**: #FFFFFF
- **Background**: #F7F9FC
- **Dark Text**: #101828
- **Secondary Text**: #667085

## Color Usage
- **Navy**: Headings, Navigation, Important UI elements, Footer, Dark sections
- **Blue**: Buttons, Links, Icons, Highlights
- **Cyan**: Gradients, Hovers, Glow effects, Tech visuals
- **White**: Extensive use for breathing room.

## Logo Usage
Use the Wravex Innovation logo correctly. Do not stretch, rotate, alter colors, or place on overly complicated backgrounds.
