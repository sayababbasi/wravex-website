# Responsive Design

## Breakpoints
- **Mobile**: 320px+
- **Tablet**: 768px+
- **Laptop**: 1024px+
- **Desktop**: 1440px+
- **Large**: 1920px+

## Mobile Rules
- One-column layouts
- Simplified navigation (Full-width panel)
- Large touch targets (Min 44x44px)
- Shorter headings, optimized images
- No horizontal overflow
