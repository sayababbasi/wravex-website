# Design System

## Philosophy
Minimal interface + strong typography + premium graphics + subtle motion.
Visual hierarchy created through typography, spacing, contrast, grid structure, and white space.

## Typography
- **Primary**: Inter, Manrope, or Plus Jakarta Sans
- **Hierarchy**:
  - Hero: 64-80px desktop, 36-42px mobile
  - Section: 42-52px desktop, 32-40px mobile
  - Card: 20-24px
  - Body: 16-18px
  - Small: 13-14px

## Spacing System
Base scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 120px

## Border Radius
- Small: 8px
- Medium: 12px
- Large: 16px
- XL: 20px
- Hero: 24-32px
